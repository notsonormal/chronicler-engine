# Decide the product behaviour, and review the dispositions that cost work

Type: grilling
Status: open
Blocked by: 03, 04, 05

## Question

1. **The behaviour questions.** Tickets 03 to 05 collect the product behaviour questions that only the owner can answer. At charting there were 14. What is the answer to each one?
2. **The dispositions that cost work.** Do you accept each disposition that is not "leave it"? The owner sees only these, each with the review sketch of its machine from tickets 03 to 05. The sketch is for validation: the owner checks the machine against intent and looks for an arrow that is missing or wrong (ticket 01).
3. **The work tickets.** For each accepted disposition, file one work ticket in `.scratch/state-machines-work/issues/`. A work ticket names its machine, its disposition, the behaviour answer it depends on and its evidence.

## Context

- Ask the behaviour questions in rounds of five, with a recommended answer for each, as `/grilling` says. A behaviour answer can change a disposition. Ask the questions of a machine before its disposition.
- A behaviour answer that changes what a player sees needs a spec scenario in `docs/specs/`. Each such scenario goes into the work ticket, and not into this ticket.
- Read the three disposition assets of tickets 03 to 05 first.
- Use `/grilling` and `/domain-modeling`. The owner answers for themselves.
