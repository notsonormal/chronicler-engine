# Grill spec intro/summary format

Type: grilling (HITL)
Status: pending

## Question

Review and decide the standard intro/summary format for `docs/specs/*.md` files. The existing specs vary in how they open; pick a consistent shape so every new spec in this map follows it.

## Scope

- What belongs in the first paragraph(s) of a spec?
- Should there be a one-line summary, a scenario overview, links to related docs, or all three?
- How should scenarios be introduced before the scenario list?
- What tone/level of detail is right for a reference spec?

## Output

- A decision on the standard intro/summary format.
- An example from one existing spec updated to the agreed format (optional).
- Tickets 04–12 update their spec drafts to match.
