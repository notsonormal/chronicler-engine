Type: prototype

## Question

Does the framework note transfer to a project outside this repo? This is the map's test of transfer (map Notes: Purpose).

First, choose the case with the owner. The form waits for the draft, because what to test depends on it. Two candidates:

- **A case from a work project** that the owner describes in words. The reference context: a team of 7 that works with several other teams, and communicates through Jira, Slack, GitHub and Confluence.
- **A public project with many writers**, for example a large open-source project with a glossary or decision records.

Then apply the note to the case, and show what it says. Mark what transfers from this repo, what changes, and what the note does not cover. The case differs from this repo in two ways:

- **The writer axis:** its writers include people who remember and can talk to each other, as well as agent sessions.
- **The number of contexts:** it has several teams, and this repo has one context.

The worked case changes nothing outside this map.

## Done when

The owner has chosen the case, the worked case is an asset (`assets/worked-case-outside.md`), and the owner has reacted to it.
