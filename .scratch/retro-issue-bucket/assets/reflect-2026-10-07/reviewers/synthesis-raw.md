  - Principle: A full-sweep mode that silently skips a language should expose a mode that covers it.
  - Reason: `already-covered` — mode 2 is explicitly labelled "full codebase scan; skips Python" and mode 3 already shows `--files src/foo.rs scripts/bar.py`; the mechanism fix is Backlog.

- **T8 — expose a prototype through the running engine's `assets/` mount instead of a file path.**
  - Principle: A prototype file served from the running engine is reachable where a container file path is not.
  - Reason: `skill-not-used` — the `prototype` skill is not in this window's invoked-skill set, and the point is a chronicler-specific serving detail, not a durable prototype-writing rule.

- **D1 — reflect should prefer mechanism routings and mark prose-only routings as weak.**
  - Principle: Findings routed as skill-body prose get dropped; mechanism routings converge.
  - Reason: `already-covered` — reflect step 4 already moves any lint/script/metadata-enforceable item from Accepted to Backlog.

- **D8 — pin a probe server to a file-locked allocated port, not a new constant.**
  - Principle: Replacing one magic port constant with another is not isolation under concurrent probes.
  - Reason: `already-covered` — the skill already says "a concurrent probe needs its own port and its own `--target-dir`"; the allocation mechanism belongs in Backlog.

## Backlog

- **Stale-claim sweep.** Pattern: ticket status is a file flag with no reclaim path, so a session that ends strands `Status: claimed` tickets the frontier then skips. Hit: tickets 68/70 stayed `claimed` after `6916556a` until the user asked, and answers were rebuilt from sub-agent transcripts. Mechanism: a script/gate step listing `.scratch/**` tickets with `Status: claimed` but no `## Answer`, plus the `issues/_resolved/` move.
- **Probe-server port allocation.** Pattern: `chronicler-ui-investigator` pins port 3001 and a shared `tmp/probe-server`, colliding with the dashboard default (3000) and with a second probe. Hit: the user had to ask for the prototype on 3000, and 3001 was chosen as a fresh constant. Mechanism: reuse the integration-test harness's file-locked port reservation (3010–3050 band) instead of a fixed constant.
- **Comment-finder Python coverage.** Pattern: `get_all_source_files()` globs only `src/**/*.rs`, `tests/**/*.rs`, `assets/*.html|css`, so `--all` silently skips every Python comment. Hit: a 10-07 sweep had to justify excluding `build.py`'s 170 pre-existing docstrings. Mechanism: extend `--all` (or add a `--all-languages` mode) to include `scripts/**/*.py` and root Python.
- **Duplicate report into the review bundle.** Pattern: `report/jscpd-report.json` (2446 clones) exists but no review input surfaces it. Hit: five review sessions hand-found *Duplicated Code* while the report sat unread. Mechanism: have `prepare_review_bundle.py` copy the jscpd top-pairs summary into the bundle, or point its README at the report.
- **Derived-number doc check.** Pattern: a count a generator knows (route count) is hand-typed into prose and rots. Hit: `56 → 57 routes` was hand-bumped across reviews until the user demanded it be removed. Mechanism: generators that emit a doc write the number themselves, or `validate_docs.py` flags numeric tokens attached to generated quantities.
- **Removed-reference sweep for skills.** Pattern: docs-only stale-reference sweeps miss `.agents/skills/`, which rots like docs. Hit: a stale `POST /check-text` reference survived in `chronicler-ui-investigator/SKILL.md` after ticket 70 removed the route. Mechanism: a check that greps docs and `.agents/skills/` for route/identifier tokens `extract_http_routes.py` no longer emits.
- **Gate-provenance record.** Pattern: the commit skill never builds, so nothing ties a committed tree to the gate run that covered it. Hit: `6077371b` shipped 33 files and new source with "I did not build or test, per the skill workflow". Mechanism: `build.py` writes a machine-readable stamp (tree hash + gate result) the commit report can cite.
