# Bypass text check for recognized slash commands

Type: task
Status: pending
Blocked by: (none)
Assignee: (unclaimed)

## Question

Bypass the player-input text check for recognized steering slash commands (`/guide`, `/narrator`, `/impersonate`) in `action_check_handler`, because steering text is an instruction to the model, not player dialogue. Unknown slash and plain input keep the check as today.

## Context

Resolved by grilling ticket 14 (Q7, decision A). The text check exists to catch errors in player-typed prose before it enters history. Steering text is not player prose:

- `/guide` — not persisted; a one-shot instruction to the model.
- `/narrator` — a directive persisted as a Narrator row, not dialogue.
- `/impersonate` — output is generated by the model, not typed.

Checking the raw command (slash prefix included) as if it were dialogue clutters the confirm flow with irrelevant flags on imperatives and fragments.

## Scope

1. **`src/adapters/driving/http/action/handlers/actions.rs::action_check_handler`** — before calling `text_check_service.check_player_input`, detect a recognized `Action::parse(&command)` variant. If the command parses to `Guide`/`Narrator`/`Impersonate`, dispatch directly (`dispatch_action`) and return, skipping the check. If it parses to `FreeAction` (unknown slash or plain input), run the existing check path unchanged.
2. **Do not** check the argument-only variant (Q7 chose A, not B). The bypass is all-or-nothing per recognized command.
3. **Test** — add an HTTP test asserting that a recognized slash command with intentionally flagged words does **not** surface a text-check preview, while a plain `FreeAction` with the same words does. Tag against the existing `docs/specs/actions.md` scenarios (1.9–1.11) or add a small scenario if a dedicated assertion is cleaner — the grilling decided no new `steering.md`, so prefer reusing existing scenarios or an invariant.
4. **Unit alternative** — if an HTTP test is awkward to frame (the check runs before dispatch), a unit test on a small extracted helper is acceptable. Prefer the tier that tests the actual branch.

## Notes

- Re-verify the current `action_check_handler` shape before editing; it calls `check_player_input(&command, mode, ignored_words)` then either renders a `TextCheckPreviewTemplate` or dispatches.
- `Action::parse` is case-insensitive on the leading slash (`/guide`/`/narrator`/`/impersonate`); unknown slash and bare input fall through to `FreeAction`.
- This is the last open behavior gap on the steering surface. The `GenerationReplay`→`SteeringRecord` rename remains a separate deferred mechanical ticket, not a gate.
