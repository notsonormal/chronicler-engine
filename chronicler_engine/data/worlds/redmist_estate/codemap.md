# chronicler_engine/data/worlds/redmist_estate/

## Responsibility
Production game world — a mystery/horror themed estate. Contains the full map, scenarios, and world manifest for the primary playable experience.

## Files
- `world.json` — World manifest (name, description, starting room, map file)
- `map.json` — Full estate map with regions, rooms, and exits
- `scenarios/` — Starting scenario definitions
