# Chronicler Engine

An interactive fiction / text-adventure engine in Rust. An LLM-driven narrative pipeline resolves player actions, persists game state across sessions, and serves an HTMX dashboard over HTTP/WebSocket.

## Prerequisites

- **Rust 1.88.0** — pinned in `rust-toolchain.toml` (edition 2024, requires 1.85+).
- **Python 3.12** — for the build/validate gate (`build.py`, `scripts/`).
- **An LLM provider** — to generate narration at runtime. Connections live in `data/settings.json` (OpenRouter and Ollama examples ship with the repo). Not needed to build or run the test suite; live-LLM tests are `#[ignore]`d by default.

## Quick start

```bash
python build.py                  # full gate: fmt + clippy + guardrails + tests (~1 min)
cargo run -- --port 3000         # run the server (defaults: redmist_estate world, julian persona)
```

Then open `http://localhost:3000`. Use `--list-worlds` to see shipped worlds.
