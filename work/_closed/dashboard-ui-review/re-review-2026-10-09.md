# Dashboard UI re-review — 2026-10-09

The final re-review for [Final re-review of the dashboard](issues/24-final-re-review.md). It uses the method of the [first review](review-2026-09-29.md). It finds one new P1 and eight new P2s, so the map is not done yet.

## Scope and method

- Tree: `75919da6` with a clean working tree. The full gate passed on this tree (`logs/build_20261009_220707.log`).
- Engine: `python build.py run -- --world redmist_estate --port 3201`. The probe has its own database (`target/debug/chronicler_3201.db`), so the user's games are not touched.
- Connections: the real ones from `data/settings.json`, as the user asked. The Narrator is `deepseek-v4-flash` on OpenRouter. The Quantifier is `ollama-gemma-4-e2b`; Ollama does not run in this container, so the Quantifier failed on every turn. That gave a real Degraded role for the whole session.
- Browser: headless Chrome 154 at 1280x856, plus one 1024x700 check (the smallest supported viewport, ticket 19).
- Exercised for real: four turns, an `/options` call and an option pick, `/impersonate`, a new Swipe and a Swipe switch, Retry on a player input, edit with Ctrl+Enter, delete, the text-check preview with "Send with edits", a Narrator failure (Narrator set to the unreachable Ollama connection), an unreachable engine (server stopped, then restarted), connection Test (pass and fail), connection Edit/Cancel, preset Duplicate/Edit/Save/Delete, World Edit/Cancel/Create (failed), game rename, new game, switch and delete.
- Screenshots: `tmp/t24/NN-*.png` (local only, `tmp/` is gitignored). Running notes: `tmp/t24/findings.md`.
- Epistemic tags: **[known]** = observed or measured; **[inferred]** = follows from code, not exercised.
- Cost: about 15 LLM calls, about US$0.01.
- Data change: only the probe database. Text Check was set back to Disabled and the Narrator back to `deepseek-v4-flash` before the session ended.

**Not covered:** Retrigger (no trigger fired in four turns, so the control never showed); a phone viewport (out of scope since ticket 19); a screen reader (the live regions and landmarks were checked in the DOM only).

## What works

- The banner and the role popover make the degraded Quantifier visible at once, and the Narrator failure names its cost ("the turn was left unnarrated").
- The unreachable state turns the banner red and clears it on recovery.
- Swipes, the restore notice, edit mode, `/options`, option pick, `/impersonate`, rename and game switching work with real calls.
- Connection Test reports pass and fail inline and writes no LLM Messages row.
- All measured text pairs pass AA; every icon-only button has a name; skip link, `<main>`, the command label and the four announcers are present.
