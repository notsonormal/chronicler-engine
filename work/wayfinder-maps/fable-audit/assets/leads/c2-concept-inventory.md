# C2 — Concept inventory: which engine concepts have little or no use today

Repository: `/workspace/chronicler-engine` at the time of writing. Read-only audit. **No deletion is recommended here.**

## Method

- **Shipped content** = `data/`, excluding `data/worlds/test` and `data/characters/test`. Those two directories are ignored in every count below.
- The shipped corpus is small: 1 World (`redmist_estate`, 11 Rooms), 5 Characters, 2 Personas (1 shipped: `julian.json`), 6 prompt presets, 1 settings file with 8 Connections.
- **Code count** = lines in the main production files (`wc -l`), plus the number of lines in `src/` that match the main identifier, excluding `*_tests.rs` and `src/test_support/` (`rg -c`).
- **Test lines** = the sum of matching lines in `tests/` and `src/**/*_tests.rs` (`rg -c`).
- Label **known** = read directly in the cited file. **inferred** = concluded from an absence after a repository-wide `rg`. **guessed** = not verified beyond the citation given.
- `not recorded` is written where no measurement was taken.

## Concepts with shipped content that never reach a prompt or the screen

6. **`provider_order`, `pin_provider_order`, `reasoning_effort`, `single_user_message`, custom samplers** — reach the request body, never the prompt text. Included here because "reaches the model prompt" is false for all five, although each does change what the model receives.
